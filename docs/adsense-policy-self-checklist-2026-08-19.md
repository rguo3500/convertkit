# ConvertKit Google AdSense 政策合规自查清单

**适用站点：** `https://lovexiaoyue.cc.cd`  
**当前状态：** AdSense 网站审核已提交；Privacy & Messaging 的 European regulations 消息已发布；正式广告脚本和真实广告位仍关闭。  
**使用方式：** 上线前逐项标记“通过 / 不适用 / 待整改”，并为关键项目保留截图、URL、部署提交和测试日志。

> 这份清单用于运营自查，不能替代 Google 的最终审核或法律专业意见。Google 会更新政策，发布商有责任持续检查官方政策页面。[1]

## 一、结论分级

| 等级 | 含义 | 处理方式 |
|---|---|---|
| 必须通过 | 可能直接影响审核、广告投放或账号状态 | 未通过前不要开启广告 |
| 发布前确认 | 需要在 AdSense、CMP 或 Cloudflare 后台确认 | 保存截图或配置记录 |
| 持续监控 | 上线后每天或每周检查 | 发现异常立即暂停相关改动 |
| 仅在变更时检查 | 域名、供应商、法律身份或广告代码变化后复核 | 变更后重新运行完整审计 |

## 五、广告代码与广告位

| 编号 | 检查项目 | 验收标准 | 当前状态 |
|---|---|---|---|
| A-01 | Client ID | 使用 AdSense 后台提供的真实 `ca-pub-...` client ID，不猜测、不混用其他项目 | 审核通过后配置 |
| A-02 | Slot ID | 每个广告位使用后台创建的真实 slot ID，并记录位置和页面 | 审核通过后配置 |
| A-03 | 环境门控 | `VITE_ADSENSE_ENABLED` 和 `VITE_ADSENSE_CONSENT_READY` 未同时满足前不加载广告 | 当前保持关闭 |
| A-04 | 静态脚本 | 未授权状态下页面源代码或运行时不应提前加载 `adsbygoogle.js` | 当前生产审计通过 |
| A-05 | 广告位隔离 | 广告不与输入框、复制、下载、结果或导航按钮重叠 | 上线后桌面/移动复核 |
| A-06 | 不放在弹窗 | 不将 AdSense 放在阻碍导航的弹窗、弹出窗口、邮件或软件内 | 必须保持 |
| A-07 | 不使用隐藏广告 | 不用不可见、非标准尺寸、遮挡内容或自动点击方式提升展示/点击 | 必须保持 |
| A-08 | 不修改广告内容 | 不改变 Google 广告代码、目标、尺寸或点击行为以提升收入 | 必须保持 |
| A-09 | 不测试真实点击 | 不点击自己的广告，不要求他人点击，不用自动化工具点击或刷新广告 | 必须保持 |
| A-10 | 不购买低质流量 | 不使用 paid-to-click、autosurf、click-exchange 或无法审计的激励流量 | 必须保持 |

Google 明确禁止人为增加展示或点击、鼓励点击、误导性广告布局和部分低质量流量来源。[1] [5]

## 六、流量、内容和站点行为

| 编号 | 检查项目 | 验收标准 |
|---|---|---|
| T-01 | 流量来源 | 主要流量来自可解释的搜索、直接访问、自然分享或可审计渠道 |
| T-02 | 无机器人流量 | 没有购买机器人、自动刷新、点击交换或异常脚本流量 |
| T-03 | 无强制跳转 | 网站不自动跳转到无关页面、不诱导下载、不安装恶意软件 |
| T-04 | 无干扰弹窗 | Cookie 消息和联系面板不妨碍核心导航；广告上线后不新增干扰性弹窗 |
| T-05 | 版权合规 | 文本、图标、图片、代码和品牌素材有合法来源或许可 |
| T-06 | 受限内容 | 页面不发布色情、违法、仇恨、欺诈、危险行为或侵犯他人权利的内容 |
| T-07 | 用户生成内容 | 如未来增加评论或上传内容，必须有审核、举报和政策机制；不得伪造评论、评分或推荐 |
| T-08 | 内容与广告比例 | 广告不能成为页面主体，尤其不能让空白区或页脚取代真实内容 |

## 九、审核期间禁止操作

在审核结果出来前，不要点击自己的广告，不要让家人、朋友、测试者点击广告，不要购买或交换流量，不要手工注入真实广告脚本，也不要为了测试而刷新真实广告位。不要频繁更换域名、运营者身份、法律地址、站点主题或 CMP 供应商。若必须修复 bug，应保留变更记录并重新运行生产 readiness 审计。

## 十、ConvertKit 当前结论

当前 ConvertKit 的主要代码和生产基线项目已经通过：网站所有权、首页核心内容、四个法律/联系页面、运营者身份、Cookie 横幅、Privacy & Messaging 发布状态、未授权请求门控、robots.txt 和 sitemap.xml。当前仍应标记为“等待 Google 审核”，而不是“正式广告已上线”。

尚未执行的项目是审核通过后的真实 client/slot 配置、Cloudflare 环境变量开启、授权状态 Network 验收、撤回后的真实广告脚本清理验证，以及正式上线记录。由于这些步骤会改变实际广告请求，必须等审核通过并确认真实后台值后执行。
